## 🛠️ Run Locally

### Prerequisites

- Node.js ≥ 18.x
- npm ≥ 9.x

### Setup

```bash
# Clone the repository
git clone https://github.com/siddhesh940/Sid_Portfolio.git

# Navigate into the project
cd Sid_Portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

> **Note:** The contact form uses EmailJS. To enable it, set `NEXT_PUBLIC_EMAILJS_SERVICE_ID`, `NEXT_PUBLIC_EMAILJS_TEMPLATE_ID`, and `NEXT_PUBLIC_EMAILJS_PUBLIC_KEY` in a `.env.local` file.

### Production build

```bash
npm run build
npm start
```
